1) Extract PCI_V1_1_ENHANCED_SOURCE.zip and open its single top-level repository folder.
2) Upload the contents of that folder (including .github/, index.html, public/, src/, scripts/, tests/, package.json, vite.config.ts) to the root of the GitHub Pages repository's main branch. Do NOT upload the wrapper ZIP into repository root instead of extracting it.
3) Keep .github/workflows/pci-pages.yml intact. GitHub Actions installs real npm dependencies on Node 22, regenerates offline test assets, runs typecheck/lint/Node/research checks, builds Vite, verifies dist, runs native Chromium smoke tests, and deploys ONLY dist/ if every required gate passes.
4) A genuine package-lock.json can only be generated after resolving dependencies (npm install); do not fabricate it. The workflow handles absent lockfile.
5) Once Actions passes, open the actual HTTPS GitHub Pages URL. Test Academy→concept→Conditioning→Archive, goal→Theater→Feedback→Archive, browser refresh and Back, sensitive-data prompts and backup export/import. Test again in iPhone Safari and verify downloaded JSON backups are unencrypted, remain in user control and contain no unwanted sensitive data. Stop release if drafts or saved entries disappear.
6) Remain at v1.1.0-rc.1 until an actual React18/Vite build and native persistence/mobile checks succeed. Do not label this source archive a production deployment artifact.
