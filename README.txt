# PSYCHO-CYBERNETICS INTELLIGENCE — Stage 08 full application source

A **local-first React / TypeScript application foundation** continuing PCI Stages 01–07. Not a separate concept demo. All 10 named module routes exist, with functional Knowledge Vault, Command Center, private note editor, settings, local backup/restore interface, and honest states for labs scheduled later.

## Important release classification

- **PASS:** strict TypeScript compilation, offline static compiler, data-loading Node tests, canonical content validation, and Chromium in-memory route/viewport smoke.
- **BLOCKED:** npm registry DNS access prevented dependency installation, creating a truthful lockfile and verifying the **React 18 + Vite production build**. `npm run build` was actually attempted and failed because Vite is not installed. Do not describe this as a validated Vite release.
- **NOT_TESTED:** real-origin IndexedDB transactions, iPhone Safari, hosted GitHub Pages navigation, assistive technology, and browser-level export/import.

## Production installation (once online)

```bash
npm install
npm run lint
npm run build
npm run dev
```

Do not commit a fabricated lockfile. An actual package-lock.json should be generated by `npm install` and retained after testing. Upload **only `dist/`** to GitHub Pages or an HTTPS static host. Hash routes support refresh and browser back/forward without a custom server fallback. Set the correct base path if changing away from `base:'./'`.

## Offline development / static fallback (executed)

```bash
npm run build:offline
```

This writes `dist-static/`, built with the available global TypeScript compiler and an **offline-only** legacy React 16 compatibility harness. It is a temporary test fallback and **not** the verified React 18 production runtime; the bridge is deliberately outside `public/`. To inspect it, serve `dist-static/` with a regular static web server. Opening a local HTML file directly in iPhone Files may not allow JSON fetches or IndexedDB, and this ZIP is not a deployed site.

## Repo map

- `src/`: React 18 source, canonical read-only repositories, typed private IndexedDB repository, routing and UI.
- `public/data/`: source-grounded book records segmented by chapter, canonical concept index, 21-day curriculum and rehearsal templates.
- `public/styles.css`: dark responsive design tokens and components.
- `reference/{knowledge,activity,personalization}/`: byte-preserved complete input packs (including their schemas, full research records, original validators and handoffs). **Never deploy this directory publicly.**
- `offline-vendor/`: source-available MIT React 16 runtime and explicitly non-production compatibility bridge for offline smoke tests.
- `dist-static/`: offline compiled preview, not a production Vite build.
- `tests/`: data access checks, structural source integrity and in-memory Chromium smoke.
- `audit/`: actual executed test reports and browser screenshots.
- `PCI_PROJECT_MANIFEST.json`, `PCI_ID_REGISTRY.json`, `PCI_ISSUES.json`: permanent continuity artifacts. The first 1,769 existing IDs are untouched; 4 software-issue IDs are new.

## Data boundaries

Static assets contain **no full copyrighted PDF, no personal journal/profile records, and no private example users**. The book's automatic success mechanism is treated as a metaphor. Source labels mean a claim is present in the edited edition, not that clinical or historical efficacy is proven.

IndexedDB name: `pci-private-v1`, schema version 2, 25 private stores. Personal entries are created only through explicit user actions. Import accepts the Stage 07 PCI_PRIVATE_EXPORT v2 envelope, preserving duplicate IDs. Exports are unencrypted and default to excluding records marked sensitive. Protect downloaded backups. Real browser migration and transaction safety must be verified/hardened in Stages 09/14.

## QA commands

```bash
npm run lint
npm run build:offline
npm run test:repo
npm run test:assets
npm run test:browser
```

`test:browser` is explicitly **in-memory React compatibility smoke**, not a hosted origin, real IndexedDB, or verified Vite browser run. Chromium policy on this environment blocked localhost and file URL navigation. The test fetches real segmented JSON from a local file-backed mock, then exercises hash-route/DOM interactions and responsive layout.
